## 📌 Featured projects

### [Redis server in C#](https://github.com/lioneddu/codecrafters-redis-csharp)
A Redis-compatible server written from scratch on raw TCP sockets: RESP protocol parsing, strings with expiry, lists with blocking pops, streams, sorted sets, geospatial commands, transactions (`MULTI` / `EXEC` / `WATCH`), Pub/Sub, `AUTH` / `ACL`, **master–replica replication** and **RDB + AOF persistence**.
`C#` `.NET` `TCP` `Concurrency` `Distributed systems`

### [Pwned Password Checker (Bloom filter)](https://github.com/lioneddu/PwnedPasswordChecker.Bloom)
WPF desktop tool that checks whether a password appears in the *Have I Been Pwned* breach dataset **entirely offline**. It streams the multi-GB SHA-1 hash list, filters it by occurrence count and compresses it into a compact Bloom filter (~7 MB embedded), with cancellation and progress reporting.
`C#` `WPF` `Probabilistic data structures` `Performance`

### [POSIX-like shell in C#](https://github.com/lioneddu/codecrafters-shell-csharp)
An interactive shell with builtins, `PATH` resolution, quoting rules, pipelines, I/O redirection, background jobs, persistent history and tab completion in raw terminal mode.
`C#` `.NET` `Processes` `Parsing`

### [HL7 v2 → FHIR converter](https://github.com/lioneddu/v2-to-fhir-converter-ws)
Web service developed for my university thesis: converts HL7 v2 ADT messages (A28, A31, A40) into FHIR Bundles, mapping Patient demographics, next of kin and visit data.
`Node.js` `Express` `HL7` `FHIR` `Healthcare`

### [Su Brincadore](https://github.com/lioneddu/su-brincadore) · [▶ Play](https://lioneddu.github.io/su-brincadore/)
